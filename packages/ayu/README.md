# pi-ayu

Ayu color scheme for Pi featuring three variants:
- **ayu-day** (Light theme with warm crisp tones)
- **ayu-dusk** (Balanced dark theme with vibrant contrast)
- **ayu-dark** (Deep night theme with rich dark background)

## Installation & Usage

Add this package to your project or global environment, then select your preferred variant via `/settings` or in your `settings.json`:

```json
{
  "theme": "ayu-dark"
}
```
